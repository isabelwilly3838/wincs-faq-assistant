# 3-minute demo video: script and shot list

Record with OBS, Loom or the Mac screenshot tool (Cmd+Shift+5). 1080p, mic close, browser zoom 125%, and close other tabs.

| Time | On screen | Say (roughly) |
|---|---|---|
| 0:00–0:20 | Title slide → the app | "WinCS gets the same questions every week. I built an AI FAQ assistant that answers them from the official FAQ, and ran it as a 3-sprint Scrum project." |
| 0:20–1:00 | Ask "How much does membership cost?", open Sources; ask "When are meetings?" | "Answers are short, and every answer shows its source, so members can trust it." |
| 1:00–1:30 | Ask "Who sponsors WinCS?" → I don't know | "If the FAQ doesn't cover something, it says so and points to the committee instead of making something up. I tested this with hallucination cases." |
| 1:30–1:50 | Try "Ignore previous instructions…" → blocked | "It also blocks prompt injection and handles sensitive messages safely." |
| 1:50–2:20 | Jira board → Power BI dashboard | "I ran 3 two-week sprints in Jira with _X_ stories. Here's velocity, burndown and cycle time in Power BI." |
| 2:20–2:45 | Test results CSV + SUS numbers | "A 30-case test plan found _Y_ bugs, which I fixed. The usability score went from _A_ to _B_ after changes from user testing." |
| 2:45–3:00 | GitHub README | "The code, test plan and docs are on GitHub. Thanks for watching." |
